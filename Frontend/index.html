University API Access Management System

A secure REST API that manages per-user API keys, enforces request limits, and controls access to student and teacher academic records. Administrators can generate keys, monitor usage, and revoke access in real time.

How it works

  1. The administrator opens the Admin Panel and generates an API key for a student or teacher.
  2. The key is shared securely with the user, who saves it on the Settings page.
  3. The student or teacher opens their portal — every request automatically sends the key in the x-api-key header.
  4. The server validates the key, checks the user's role, and enforces the configured request limit.
  5. The admin can monitor usage, raise limits, or revoke a key at any time.
